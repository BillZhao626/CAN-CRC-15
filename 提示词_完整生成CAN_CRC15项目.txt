【模块1：can_crc15_core（标准LFSR实现 + Phase 1功能）】

接口定义（包含Phase 1并行和错误注入接口）：
```verilog
module can_crc15_core #(
    parameter CRC_POLY = 15'h4599
)(
    // 时钟与复位
    input  wire         clk,           // 系统时钟（推荐≥500MHz）
    input  wire         rst_n,         // 异步复位（低有效）
    
    // 数据接口（位流输入，符合CAN控制器接口）
    input  wire         data_valid,    // 数据有效信号（高电平表示当前周期输入1位）
    input  wire         data_in,       // 串行输入数据（CAN总线位流）
    input  wire         is_stuffed,    // 位填充标志（高电平表示当前位为填充位，需跳过CRC计算）
    
    // 并行输入接口（Phase 1新增）
    input  wire [7:0]   data_parallel, // 8位并行输入数据
    input  wire         parallel_mode, // 并行模式使能（1=并行, 0=串行）
    input  wire [2:0]   data_width,    // 并行数据宽度（0=1位, 1=2位, ..., 7=8位）
    
    // 控制接口
    input  wire         crc_init,      // CRC初始化（高脉冲复位CRC为0x0000）
    input  wire         crc_enable,    // CRC计算使能（低电平时保持CRC状态）
    input  wire         frame_end,     // 帧结束信号（自动复位CRC）
    input  wire         error_frame,   // 错误帧信号（自动复位CRC）
    
    // 错误注入接口（Phase 1新增）
    input  wire         test_mode,     // 测试模式使能
    input  wire [2:0]   error_position, // 错误位置（0-7位）
    input  wire         error_enable,  // 错误使能（在当前error_position注入错误）
    
    // CRC输出
    output wire [14:0]  crc_out,       // 当前CRC值（实时输出）
    output wire [14:0]  crc_out_rev    // CRC位序反转输出（符合CAN协议REFOUT=1要求）
);
```

功能模块（包含Phase 1实现）：
1. 并行到串行转换逻辑（Phase 1）：
   - parallel_buffer[7:0]：8位并行数据缓冲
   - parallel_cnt[2:0]：当前处理的位计数（0-7）
   - parallel_valid：并行数据有效标志
   - 选择逻辑：parallel_mode时使用parallel_buffer[parallel_cnt]，否则使用data_in

2. 错误注入逻辑（Phase 1）：
   - bit_position[2:0]：当前位位置（串行模式计数，并行模式使用error_position）
   - error_active：错误激活标志
   - 实现：在test_mode && error_enable && (bit_position == error_position)时，对数据取反

3. 位填充检测逻辑：
   - 5位历史寄存器（bit_history[4:0]）
   - 检测连续5个相同位
   - 生成stuff_expected标志（下一位为填充位）
   - 仅记录非填充位到历史

4. CRC-15核心计算（Galois型LFSR）：
   - 15位CRC寄存器（crc_reg[14:0]）
   - 反馈路径：feedback = crc_reg[14] ^ data_in_with_error（含错误注入后的数据）
   - 反馈tap位置（根据多项式0x4599）：
     * crc_next[0]  = feedback
     * crc_next[3]  = crc_reg[2] ^ feedback
     * crc_next[4]  = crc_reg[3] ^ feedback
     * crc_next[7]  = crc_reg[6] ^ feedback
     * crc_next[8]  = crc_reg[7] ^ feedback
     * crc_next[10] = crc_reg[9] ^ feedback
     * crc_next[14] = crc_reg[13] ^ feedback
     * 其他位：直接移位（crc_next[i] = crc_reg[i-1]）
   - 更新条件：data_valid_processed && crc_enable && !is_stuffed
   - 自动复位：frame_end或error_frame触发时自动复位CRC为0x0000
   - 初始化：crc_init或rst_n时复位为0x0000

5. 输出接口：
   - crc_out = crc_reg（直接输出）
   - crc_out_rev = 位序反转（bit[0]<->bit[14]）

genvar i;
generate
    for (i = 0; i < 15; i = i + 1) begin : srl16e_chain
        (* KEEP = "TRUE" *)
        SRL16E #(
            .INIT(16'h0000)
        ) u_srl16e (
            .D(crc_next_srl[i]),    // 输入来自CRC计算逻辑
            .CLK(clk),
            .CE(srl_ce),            // 使能=data_valid && crc_enable && !is_stuffed

Phase 1功能实现（使用generate块）：
1. 并行输入逻辑（ENABLE_PARALLEL == 1时生成）：

   - parallel_cnt_srl[2:0]：位计数
   - parallel_valid_srl：有效标志
   - 串行化逻辑：逐位从parallel_buffer_srl[parallel_cnt_srl]输出

2. 错误注入逻辑（ENABLE_ERROR_INJECT == 1时生成）：
   - bit_position_srl[2:0]：位位置跟踪
   - error_active_srl：错误激活标志
   - 实现：error_active_srl ? ~data_in_srl : data_in_srl（取反注入错误）

CRC反馈逻辑（与标准版相同，但使用处理后的数据）：
- feedback_srl = srl_out[14] ^ data_in_with_error_srl（包含错误注入）

位填充检测：与标准版相同（5位寄存器bit_history_srl）

自动复位逻辑：
- auto_reset_srl = frame_end | error_frame
- SRL16E在自动复位时输入为0

输出接口：
- crc_out = srl_out
- crc_out_rev = 位序反转（{srl_out[0], srl_out[1], ..., srl_out[14]}）

task feed_bit(input bit_value);
    begin
        @(posedge clk);
        data_valid = 1;
        data_in = bit_value;
        is_stuffed = 0;
        parallel_mode = 0;  // 串行模式
        @(posedge clk);

task feed_bit_sequence(input integer num_bits, input [63:0] bit_data);
    integer i;
    begin
        for (i = num_bits - 1; i >= 0; i = i - 1) begin  // MSB先！
            feed_bit(bit_data[i]);
        end
    end
endtask
