【模块1：can_crc15_core（标准LFSR实现）】

接口定义：
```verilog
module can_crc15_core #(
    parameter CRC_POLY = 15'h4599
)(
    input  wire         clk,           // 系统时钟（推荐≥500MHz）
    input  wire         rst_n,         // 异步复位（低有效）
    input  wire         data_valid,    // 数据有效信号
    input  wire         data_in,       // 串行输入数据（CAN位流）
    input  wire         is_stuffed,    // 位填充标志
    input  wire         crc_init,      // CRC初始化
    input  wire         crc_enable,    // CRC计算使能
    output wire [14:0]  crc_out,       // 当前CRC值
    output wire [14:0]  crc_out_rev    // CRC位序反转输出
);
```

功能模块：
1. 位填充检测逻辑：
   - 5位历史寄存器（bit_history[4:0]）
   - 检测连续5个相同位
   - 生成stuff_expected标志（下一位为填充位）
   - 仅记录非填充位到历史

2. CRC-15核心计算（Galois型LFSR）：
   - 15位CRC寄存器（crc_reg[14:0]）
   - 反馈路径：feedback = crc_reg[14] ^ data_in
   - 反馈tap位置（根据多项式0x4599）：
     * crc_next[0]  = feedback
     * crc_next[3]  = crc_reg[2] ^ feedback
     * crc_next[4]  = crc_reg[3] ^ feedback
     * crc_next[7]  = crc_reg[6] ^ feedback
     * crc_next[8]  = crc_reg[7] ^ feedback
     * crc_next[10] = crc_reg[9] ^ feedback
     * crc_next[14] = crc_reg[13] ^ feedback
     * 其他位：直接移位（crc_next[i] = crc_reg[i-1]）
   - 更新条件：data_valid && crc_enable && !is_stuffed
   - 初始化：crc_init或rst_n时复位为0x0000

3. 输出接口：
   - crc_out = crc_reg（直接输出）
   - crc_out_rev = 位序反转（bit[0]<->bit[14]）

【模块2：can_crc15_srl16e_optimized（SRL16E优化版）】

接口定义：与模块1相同

优化重点：
1. 使用Xilinx SRL16E原语替代15个DFF
2. 资源估算：LUT≈32，寄存器≈8，SRL16E=15
3. 最大频率：≥550MHz

SRL16E实例化（15个）：
```verilog
genvar i;
generate
    for (i = 0; i < 15; i = i + 1) begin : srl16e_chain
        (* KEEP = "TRUE" *)
        SRL16E #(
            .INIT(16'h0000)
        ) u_srl16e (
            .D(crc_next_srl[i]),    // 输入来自CRC计算逻辑
            .CLK(clk),
            .CE(srl_ce),            // 使能=data_valid && crc_enable && !is_stuffed
            .A3(1'b1),              // 地址=15（16位深度）
            .A2(1'b1),
            .A1(1'b1),
            .A0(1'b1),
            .Q(srl_out[i])
        );
    end
endgenerate
```

CRC反馈逻辑（与标准版相同）：
- feedback_srl = srl_out[14] ^ data_in
- crc_next_srl[i]的计算方式与标准版crc_next[i]完全一致

位填充检测：与标准版相同（5位寄存器）

输出接口：
- crc_out = srl_out
- crc_out_rev = {srl_out[0], srl_out[1], ..., srl_out[14]}

【模块3：can_crc15_parallel_core（并行CRC-15核心）】

接口定义：
```verilog
module can_crc15_parallel_core #(
    parameter CRC_POLY = 15'h4599,
    parameter PAR_WIDTH = 8,           // 并行宽度：1, 8, 16, 32
    parameter CRC_WIDTH = 15
)(
    // 时钟与复位
    input  wire                    clk,
    input  wire                    rst_n,
    
    // 并行数据接口
    input  wire                    data_valid,     // 数据有效信号
    input  wire [PAR_WIDTH-1:0]    data_in,        // 并行输入数据
    input  wire                    is_stuffed,     // 位填充标志
    input  wire [PAR_WIDTH-1:0]   stuff_mask,     // 位填充掩码（1=填充位）
    
    // 控制接口
    input  wire                    crc_init,       // CRC初始化
    input  wire                    crc_enable,     // CRC计算使能
    
    // 测试模式接口
    input  wire                    test_mode,      // 测试模式使能
    input  wire [14:0]            error_inject,   // 错误注入向量
    input  wire                    error_enable,   // 错误注入使能
    
    // CRC输出
    output wire [14:0]             crc_out,        // 当前CRC值
    output wire [14:0]             crc_out_rev,    // CRC位序反转输出
    output wire [14:0]             crc_debug       // 调试输出（测试模式）
);
```

并行CRC计算核心逻辑：
1. **并行位填充检测**：
   - 检测并行数据中的连续相同位
   - 生成stuff_mask掩码
   - 仅对非填充位进行CRC计算

2. **并行CRC-15计算**：
   - 使用查表法实现并行CRC计算
   - 预计算8/16/32位并行CRC查找表
   - 支持动态并行度切换

3. **错误注入测试模式**：
   - 支持单bit错误注入
   - 支持多bit错误注入
   - 支持突发错误模式
   - 提供调试接口

【辅助任务函数】
```verilog
// 发送单个位
task feed_bit(input bit_value);
    begin
        @(posedge clk);
        data_valid = 1;
        data_in = bit_value;
        is_stuffed = 0;
        @(posedge clk);
        data_valid = 0;
    end
endtask

// 发送位序列（MSB先传输）
// 关键：从num_bits-1循环到0（MSB first）
task feed_bit_sequence(input integer num_bits, input [63:0] bit_data);
    integer i;
    begin
        for (i = num_bits - 1; i >= 0; i = i - 1) begin  // MSB先！
            feed_bit(bit_data[i]);
        end
    end
endtask

// 发送并行数据
task feed_parallel_data(input [PAR_WIDTH-1:0] data, input [PAR_WIDTH-1:0] stuff_mask);
    begin
        @(posedge clk);
        data_valid = 1;
        data_in = data;
        stuff_mask = stuff_mask;
        @(posedge clk);
        data_valid = 0;
    end
endtask

// 错误注入测试
task inject_error(input [2:0] error_type, input [4:0] error_position, input [14:0] error_pattern);
    begin
        @(posedge clk);
        test_mode = 1;
        error_type = error_type;
        error_position = error_position;
        error_pattern = error_pattern;
        error_enable = 1;
        @(posedge clk);
        error_enable = 0;
    end
endtask
```
